# IS–LM / Mundell–Fleming Macroeconomic Analysis

This project presents an empirical analysis of the IS–LM / Mundell–Fleming framework using quarterly U.S. macroeconomic data from the FRED database for the period 1990–2024.

## Project Overview

The analysis examines the relationships between real GDP, interest rates, government spending, the money supply, the CPI price index, and the real exchange rate.

The project includes:

- Data preparation and transformation
- IS equation estimation
- LM equation estimation
- Vector Autoregression (VAR) modeling
- Impulse Response Functions (IRFs)
- Macroeconomic interpretation of the empirical results

## Tools

- Matplotlib

- FRED economic data
